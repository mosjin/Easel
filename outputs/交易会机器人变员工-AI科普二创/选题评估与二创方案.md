# 选题评估与二创方案 · 交易会机器人变员工

> 画像：AI科普｜主阵地：微信公众号 + 视频号｜评估日期：2026-10-18

## 一、热点概况

- 事件：第140届交易会第一期（10月15日-19日）服务机器人专区火爆，机器人不再只做展示，而是在展馆里担任讲解员、咖啡派送员，展区外还有灭火机器狗、仓库分拣、外骨骼、擦窗等应用展示。有的媒体把这一变化概括为「从展品变员工」。
- 节点：今年是交易会创办70周年；本届会期至11月4日，3.2万家企业参展。
- 热度等级：A级（行业热议）。多家媒体集中报道；但 10月18日微博热搜前十没有它，属于行业热，不是全民热。
- 生命周期：高峰期。相关报道 10月17日发出，第一期 10月19日结束，最佳窗口还剩 24-48 小时；整个交易会到 11月4日，后续还有第二、三期，但「机器人变员工」这个具体话题会先降温。

## 二、关联度判断

- 与账号赛道关联度：高。
- 原因：AI科普的核心内容方向就是 AI 工具、AI 现象、AI 与普通人的关系；机器人上岗正好落在「AI 怎么进入工作」这条主线上。
- 适配平台：公众号适合讲透「怎么判断真上岗」；视频号适合用 50-60 秒讲「三关」。抖音、小红书可以后用角度 C 切情绪。
- 需要注意：交易会本身偏 B2B，普通读者对「展馆、采购商、订单」兴趣有限。必须把事件翻译成「你的工作会不会被拆走」，否则会写成行业资讯。

## 四、结论

**做，综合 73/100。** 但只做「判断框架」，不做「交易会机器人好厉害」的资讯汇总。

理由：热点与账号高度匹配，制作成本低，且有明显的角度空白。它的短板是时效短、变现弱，所以更适合当成一次「认知增量」内容，而不是长期栏目。

## 五、三个差异化二创角度

### 角度 A：上岗体检（推荐指数 ★★★★★）

- 核心观点：机器人确实在交易会「上班」了，但展馆是它们最容易考满分的考场。真上岗要看三关：能不能连续干、普通人能不能用、出错谁兜底。
- 形式：公众号长图文 1200-1400 字；视频号 50-60 秒口播。
- 标题候选：
  1. 机器人在交易会「上班」了？先别急着担心失业，它们还没过这三关
  2. 看了交易会的「机器人员工」，我发现大家担心的方向错了
  3. 机器人从展品变员工，真正的分水岭不是会不会后空翻
- 内容大纲：
  1. 现场：讲解员、咖啡派送员、灭火机器狗、仓库分拣、外骨骼、擦窗机器人。
  2. 泼冷水：展馆地面平、路线固定、旁边有工程师，演示不等于上岗。
  3. 三关：连续工作能力、普通人可操作性、出错后的责任与安全兜底。
  4. 真正的变化：场景在为机器人改造，机器人接走的是重复、危险、没人愿意干的活。
  5. 对普通人的意义：岗位被拆成任务，先被接走的是标准化片段；判断、沟通、处理意外还在人手里。
- 差异化：大多数报道在写「机器人火了」，这条给读者一把判断的尺子。热点会过去，尺子能留下。
- 风险：不要把展馆演示说成全面落地；不要下「某个职业将消失」的结论。

### 角度 B：任务拆解（推荐指数 ★★★★☆）

- 核心观点：机器人接走的不是「岗位」，是一段一段的「任务」。先被接走的是重复、标准、危险的片段；最后才是判断、沟通和承担责任。
- 形式：公众号/知乎长文；可配一张「岗位拆成任务」的示意表。
- 标题候选：
  1. 机器人接走的不是岗位，是一段一段的活
  2. 你的工作会不会被机器人接手？先看它能不能被拆成这几步
  3. 交易会上的机器人员工，提醒了我一件事：岗位正在被拆开
- 内容大纲：
  1. 用展馆里的讲解、送咖啡、分拣、擦窗举例，拆出「任务」。
  2. 哪些任务容易被标准化，哪些任务难以标准化。
  3. 企业算账：一台机器人替掉的不是一个人，而是一段可重复的工时。
  4. 普通人的应对：往异常处理、跨部门沟通、责任承担的方向走。
- 差异化：把「替代焦虑」翻译成「任务拆解」，读者能自己对号入座。
- 风险：容易写成职场鸡汤；必须用具体任务和现场例子撑住。

### 角度 C：补位叙事（推荐指数 ★★★★☆）

- 核心观点：机器人最先接手的，是那些没人愿意干、干不动、干了有危险的活。它不是来抢饭碗，是来补一段人干不了的事。
- 形式：视频号/小红书图文；情绪更强，适合二次分发。
- 标题候选：
  1. 交易会最动人的一幕，不是机器人后空翻，是有人重新站了起来
  2. 机器人先接手的，是那些没人愿意干的活
  3. 看了交易会的外骨骼机器人，我对「抢饭碗」这件事没那么慌了
- 内容大纲：
  1. 外骨骼：下半身瘫痪近五年的境外采购商，现场体验后重新站立。
  2. 消防机器狗、擦窗机器人、仓库分拣：先接的是危险、重复、招工难的活。
  3. 机器人补位之后，人的工作往哪走。
  4. 收束：不神化机器人，也不低估人的判断。
- 差异化：从「替代」转到「补位」，有人情味，适合视频号传播。
- 风险：残障案例不能消费，避免煽情和特写；不点具体人名；事实以公开报道为准。

## 六、发布策略

- 首发：公众号，10月18日晚或10月19日早。第一期10月19日结束，尽量赶在闭幕前。
- 同步：视频号发 50-60 秒口播版；知乎次日发角度 B 的加长版；小红书/抖音后用角度 C 切情绪。
- 标签：#交易会 #机器人 #具身智能 #AI科普 #打工人
- 互动：结尾问「你身边有没有已经上岗的机器人？」；转发语可用「转给担心被替代的朋友」。
- 原创：公众号发布时点原创声明；视频号发表页如有原创选项则勾选。
- 排版：公众号正文默认 16px；封面主标题「机器人上岗前，先过这三关」。

## 七、风险提醒

1. **别把演示当落地。** 展馆是受控环境，真实场景的稳定性、维护、安全责任都还没解决。文中要明确这层。
2. **别编数字。** 不写「将替代 X% 岗位」这类没有来源的预测；只用公开报道里的参展规模、展品数量等事实。
3. **别消费残障案例。** 外骨骼故事只作为「补位」的例子，不点人名，不煽情，不替当事人下结论。
4. **别制造失业恐慌。** 结论落到「任务被拆解」，不落到「某个职业消失」。
5. **别写成民族自豪稿。** 账号的差异点是认知增量，不是口号。

## 八、事实核验

完整原文链接见 `事实核验与原文链接.md`。以下只列核验结论，不写具体媒体名。

- 第140届交易会 10月15日开幕，第一期 10月15日-19日，会期至11月4日；今年是创办70周年；3.2万家企业参展，展览规模155万平方米，64%的参展企业应用工业互联网、人工智能等新技术。
