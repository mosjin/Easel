针对不同平台使用适合它的**文字海报封面**，而非纯画面封面。

**Why:** 用户全局规则（2026-10-23），文字海报让受众一眼看到钩子，比纯画面转化更好。

**How to apply:**
- 视频号/抖音/快手：竖版 9:16，大标题文字 + 背景，文字即钩子句
- 小红书：3:4，文字卡封面，主标题 + 副标题
- B站：横版 16:9，标题 + 视觉背景
- 公众号：2.35:1，大字标题封面

生成方式优先：Python PIL 叠加文字（文字渲染精准）> glm-image（中文文字渲染差）。

**装饰元素规范（2026-10-23）：**
- 不用装饰性红线/红色横条/侧边竖条，避免模板感
- 重点文字可保留红色作钩子色，结构性线条去掉
